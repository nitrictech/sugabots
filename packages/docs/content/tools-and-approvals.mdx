Tools let a bot do things: read a web page, search, or work in your apps through
a [connection](/docs/connections). You decide which tools each bot gets, and
which ones need a person to say yes.

## Built-in tools

Every bot comes with these while the workspace allows [web search](/docs/web-search),
unless someone turns them off for it.

<BuiltInTools />

- **Read web pages** reads public pages only. It can't sign in to anything, and
  it can't reach your private network unless the installation allows it with
  [`ALLOW_PRIVATE_WEB_FETCH_NETWORK`](/docs/configuration#network).
- **Search the web** uses the workspace's [search provider](/docs/web-search#choose-a-provider).

To switch one off for a bot, open the bot's settings, go to **Tools**, and use
**Turn off**.

Bots can also [ask each other for help](/docs/conversations#bots-asking-bots).
That's always on.

## Tools from connections

A connection's tools belong to its project, a bot's own to its default
project. Each tool has its own approval:

| Approval | What happens |
| --- | --- |
| Off | Every call is refused, and the bot is told the tool is off |
| Ask | Every call waits for a person |
| Allow | Every call runs straight away |

Until someone chooses, a tool is on **Allow** when the app says it only reads,
on **Off** when the app says it deletes or overwrites, and on **Ask** otherwise.
A choice stays, even while the app stops listing the tool. Turning a tool off
also stops a call someone already allowed but that hasn't run yet.

To change them, open **Connections** beside the bot's threads. Each row's
menu sets every tool of that connection at once, and says **Custom** when they
differ. Open a connection to see its tools, the ones that read apart from the
ones that make changes: each group's menu sets all of its tools, and each tool
can be set on its own.

## Who can answer

A waiting call shows in the chat with **Allow** and **Deny**. Allow lets that
one call run. There's no "always allow": the next call asks again.

- **Anyone who can talk to the bot**, except viewers, can answer approvals in
  its threads. In a project, anyone in it except viewers can answer.
- **Viewers** see "Waiting for someone with permission to answer this."
- **Only those who manage the automation** can answer approvals raised by an
  [automation](/docs/automations) run: for a bot's own, the bot's creator, the
  owner and admins; for a project's, the owner and admins. On your Personal
  Assistant, that's you.
- **Only those who manage the computer** can allow it to reach an internet
  address it couldn't before: for a bot's own computer, the bot's creator,
  the owner and admins; for a [project's computer](/docs/projects#computer),
  the owner and admins.
