---
title: Configuration
description: The environment variables for hosting a Sugabots installation.
---

Sugabots reads its settings from environment variables. With Docker Compose,
set them under `environment` in `compose.yml`.

## Database

| Variable              | Default        | Description |
| --------------------- | -------------- | ----------- |
| `DATABASE_URL`        | Required       | PostgreSQL connection string. It may go through a transaction pooler such as PgBouncer when `DATABASE_DIRECT_URL` is set. |
| `DATABASE_DIRECT_URL` | `DATABASE_URL` | A direct connection to PostgreSQL, set when `DATABASE_URL` goes through a transaction pooler. The workflow engine's locks and live updates use it, in a pool of up to 6 connections. |
| `DATABASE_POOL_SIZE`  | `10`           | The most connections the server's main pool opens on `DATABASE_URL`. Sign-in holds up to 2 more. Without a pooler, keep the total under the database's `max_connections`, less what its host reserves. |

## Server

| Variable                   | Default                                | Description                                                                                                                                               |
| -------------------------- | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NODE_ENV`                 | `production`                           | `development` or `production`.                                                                                                                            |
| `PORT`                     | `3000`                                 | Port the API binds.                                                                                                                                       |
| `PUBLIC_URL`               | `http://localhost:` followed by `PORT` | Where a browser reaches the API, without its `/api` path. Links in emails and OAuth redirects start here, so it must not be a container-internal address. |
| `WEB_APP_URL`              | `PUBLIC_URL`                           | Where the web app is served, when it is hosted apart from the API. Invite links and connection sign-ins return here.                                      |
| `SUGABOTS_SKIP_MIGRATIONS` | `false`                                | Docker image only. Set to `true` to skip applying pending migrations on start.                                                                            |

## Secrets

Generate each with `openssl rand -base64 32`. Keep them private and backed up.

| Variable                     | Default  | Description                                                                                                                                  |
| ---------------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `BETTER_AUTH_SECRET`         | Required | Signing key for sessions and tokens. Changing it signs everybody out.                                                                        |
| `CREDENTIALS_ENCRYPTION_KEY` | Required | Seals every stored credential: model and search provider keys, connection secrets, and connection sign-ins. Losing it makes them unreadable. |

## Access

| Variable                     | Default  | Description                                                                                                                                                                                                                                                                    |
| ---------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `SIGNUP_MODE`                | `closed` | Who may create an account. `closed`: nobody signs themselves up; people arrive by invitation to a workspace, except the first account on a new installation. `referral`: also anybody with a member's [referral link](/docs/people-and-roles#referral-links). `open`: anybody. |
| `REQUIRE_EMAIL_VERIFICATION` | `false`  | Whether a new account must open a link in its inbox before it gets a session. With the console email provider, the link is printed to the server's console.                                                                                                                    |

## Network

| Variable                               | Default | Description                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------------------------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ALLOW_UNSAFE_WORKSPACE_URLS`          | `false` | Whether the addresses a workspace gives, for its model and search providers and its connections, may be plain HTTP or on a local network such as localhost or your LAN. Unsafe because plain HTTP is unencrypted and a workspace can then reach whatever else is on your network. Turn it on for a self-hosted install using Ollama, LM Studio, vLLM, local MCP servers and the like; keep it off on an installation serving other people's workspaces. |
| `ALLOW_PRIVATE_WEB_FETCH_NETWORK`      | `false` | Whether an agent's `web_fetch` tool may read pages at private addresses. Turn it on for a self-hosted install whose agents should read an intranet.                                                                                                                                                                                                                                                                                                     |
| `ALLOW_PRIVATE_MODEL_PROVIDER_NETWORK` | `false` | Deprecated: use `ALLOW_UNSAFE_WORKSPACE_URLS`, which takes precedence when both are set. Still read, with a warning in the logs.                                                                                                                                                                                                                                                                                                                        |

## Email

| Variable                   | Default                | Description                                                                                                                                                                                                           |
| -------------------------- | ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `EMAIL_PROVIDER`           | `console`              | `console`, which prints each email to the server's log, `webhook` or `resend`.                                                                                                                                        |
| `EMAIL_WEBHOOK_URL`        | Required for `webhook` | Receives each email as JSON: `from`, `to`, `cc`, `bcc` and `replyTo` as `{email, name}` addresses, `subject`, and `text` and/or `html`. Must use HTTPS in production, and answer with a 2xx status within 15 seconds. |
| `EMAIL_WEBHOOK_TOKEN`      | None                   | For `webhook`. Sent as a bearer token with each delivery.                                                                                                                                                             |
| `EMAIL_RESEND_API_KEY`     | Required for `resend`  | A [Resend API key](https://resend.com/api-keys) with permission to send.                                                                                                                                              |
| `EMAIL_TRANSACTIONAL_FROM` | Required in production | Sender of emails a user's own action triggers, such as verification and invitations, like `Sugabots <no-reply@example.com>`.                                                                                          |

## File storage

| Variable              | Default    | Description                                                                                                                            |
| --------------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `BLOB_STORE_PROVIDER` | `postgres` | Where files are kept, such as tool results too large to hand a model whole. `postgres` keeps them in the database, up to 100 MiB each. |

## Web app

Vite inlines anything prefixed `VITE_` into the bundle, so nothing secret goes
here.

| Variable       | Default                         | Description                                                                            |
| -------------- | ------------------------------- | -------------------------------------------------------------------------------------- |
| `VITE_API_URL` | `/api` on the page's own origin | Where the API is, path included. Set it when the web app is hosted apart from the API. |
