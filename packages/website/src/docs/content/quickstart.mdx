title: Quickstart
description: Run Sugabots on your own computer in about ten minutes.

This guide runs PostgreSQL in Docker, and the web app and API straight on your
machine. It's the simplest way to try Sugabots, or to run it for yourself on one
computer.

## Before you start

You need three things installed:

- [Node.js](https://nodejs.org/) 26 or newer (`.nvmrc` has the exact version)
- [Bun](https://bun.sh/) 1.4.2 or newer
- [Docker](https://docs.docker.com/get-docker/) with Docker Compose

Check they're all there:

```sh
node --version
bun --version
docker compose version
```

## Set it up

<Steps>

1. Get the code

   ```sh
   git clone https://github.com/nitrictech/sugabots.git
   cd sugabots
   bun install
   ```

2. Make your settings file

   ```sh
   cp .env.example .env
   ```

   Open `.env` and replace the two development keys with fresh ones. Run this
   once for each key, and paste in what it prints:

   ```sh
   openssl rand -base64 32
   ```

   ```dotenv title=".env"
   BETTER_AUTH_SECRET=<the first value>
   CREDENTIALS_ENCRYPTION_KEY=<the second value>
   ```

   Everything else is already set up for your own computer.

3. Start the database

   ```sh
   docker compose up -d
   bun run db:migrate
   ```

   `docker compose ps` should show `postgres` as `healthy` before you migrate.

4. Start Sugabots

   ```sh
   bun run dev
   ```

   Keep this terminal open. The first time, Portless sets up HTTPS for local
   addresses and may ask for your password.

5. Say hello

   Open [https://sugabots.localhost](https://sugabots.localhost) and create your
   account. You're the first one in, so the installation is yours. Emails, such
   as your verification link, are printed in the terminal.

</Steps>

<Careful title="Keep .env safe">

Back it up, and keep it private. Losing `CREDENTIALS_ENCRYPTION_KEY` makes every
saved API key unreadable. Changing `BETTER_AUTH_SECRET` signs everybody out.

</Careful>

## What's running

| Service          | Address                                 |
| ---------------- | --------------------------------------- |
| Web app          | https://sugabots.localhost              |
| API              | https://sugabots.localhost/api          |
| API health check | https://sugabots.localhost/api/health   |
| PostgreSQL       | `localhost:5436`                        |

The web app and the API share one address: the API answers under `/api`. Your
data lives in the `sugabots_postgres_data` Docker volume, so it survives
restarts.

<Tip title="Something not loading?">

Portless gives the app its local names and HTTPS. `bunx portless list` shows
what it's serving, and `bunx portless doctor` checks its setup.

</Tip>
