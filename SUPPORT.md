# Getting help with Sugabots

## Questions and help

Ask on the [Sugabots Discord](https://sugabots.ai/discord). That's the place
for help installing or configuring Sugabots, choosing models and connections,
and talking through ideas. The [docs](https://sugabots.ai/docs) cover
installing, hosting, configuration and each part of the app.

Please don't open a GitHub issue for a question: issues are for tracking work.

## Bugs and feature requests

[Open an issue](https://github.com/nitrictech/sugabots/issues/new/choose) and
choose a form; the bug report form asks for what we need to reproduce the bug.
Search the [existing issues](https://github.com/nitrictech/sugabots/issues)
first, and if one already covers it, add your details there.
